# 智慧环保渗沥液平台实施计划

## 建设内容
- 建立固定顶部玻璃导航，左侧三个图标菜单、中央平台大标题、右侧三个图标菜单。
- 建立六个独立页面：总览驾驶舱、水质监测、渗沥液收集、处理工艺、设备运维、预警管理。
- 六页采用不同信息编排，并分别组合指标卡、折线图、柱状图、雷达图、饼图、表格与状态指示器。
- 加入环保处理设施背景图、毛玻璃半透明面板、青绿流光边框、悬停浮起和克制的数据动效。
- 适配桌面与移动端；小屏保留六个菜单可用性和图表可读性。

## 视觉方向
- 采用已选的 Frosted Glass Command 结构与生态蓝绿主色。
- 使用 Space Grotesk 标题和 DM Sans 正文，数据数字强化高光与层次。
- 卡片圆角保持克制，避免通用后台感和过度装饰。

## 技术细节
- 使用 ECharts 渲染真实折线、柱状、雷达、饼图，并正确处理窗口缩放。
- 共享导航与卡片视觉系统，各页面独立配置内容和图表。
- 为六个页面分别配置标题、描述与社交分享信息。
- 完成后检查页面切换、图表渲染、桌面与移动端排版及构建状态。
